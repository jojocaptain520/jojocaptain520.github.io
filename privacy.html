隐私政策

最后更新：2026 年 11 月 9 日 · 适用于 火星桌面 ZkDesk 1.0.0.0

提示：本政策说明「火星桌面」（ZkDesk）如何处理信息，数据默认留在你的电脑上。

一、适用范围与基本原则

1.1 本政策适用于「火星桌面」（英文名 ZkDesk，下称「本软件」）的 Windows 客户端，以及以 explus.work 名义发布的官网 https://www.explus.work。

1.2 我们遵循必要与最小化原则：能留本地的就不联网，必须联网的只发送完成功能所必需的内容；本软件不设账号，无内购与订阅。

二、我们收集什么、不收集什么

2.1 我们不收集姓名、手机号、邮箱、账号密码、通讯录、精确位置等身份信息，也不收集文件内容、便签与待办正文。本软件不接入统计或广告脚本，官网不使用 Cookie。

2.2 我们没有账号服务器，不提供云同步，也不在服务器上保存你的个人数据；实现功能时仅发起第四条所列请求（如天气城市）。

2.3 为接管桌面绘制，本软件仅在本地读取桌面图标与文件信息；联网仅限第四条所列请求。

2.4 任何联网请求都会披露你的 IP 地址与请求头，这是网络通信的必要条件，第三方日志我们无法控制。

三、本地存储与数据目录

3.1 数据保存在 %LOCALAPPDATA%\ZkDesk：zkconfig.dat（QSettings 格式，含程序设置与窗口状态）、盒子布局、便签与待办、天气与资讯缓存、更新历史。

3.2 上述数据仅存于本机，不会上传；其安全依赖你的 Windows 账户与磁盘保护，建议设置账户密码并启用 BitLocker。

3.3 本软件还在 HKCU 写入开机启动与屏保注册项，仅影响当前用户，不修改系统级配置。

四、联网请求明细

除下表所列外，本软件不主动联网，且不携带文件内容、便签或待办正文。

功能请求目标目的是否含个人信息
检查更新更新服务器（版本清单）判断是否有新版本不含账号与文件内容；披露 IP 与请求头
天气组件Open-Meteo（天气、空气质量、地理编码）显示所选城市天气与空气质量含城市名称及经纬度；不含账号身份

4.1 检查更新在启动约 60 秒后静默执行一次，此后每 24 小时最多一次；关闭天气或资讯组件后不再请求。

五、第三方服务

5.1 Open-Meteo 提供天气、空气质量与地理编码数据，详见其隐私政策；资讯来源（如百度热搜等公开榜单）的内容版权与数据处理由原服务方负责。

5.2 GitHub / GitHub Pages 托管官网与 Issues 反馈，更新服务器发布版本清单与安装包；WebView2 渲染网页屏保，若为在线网页会产生对应请求。

5.3 上述服务由独立主体运营，服务器可能位于境外，请求可能构成数据跨境传输。

六、系统权限说明

6.1 桌面读取：读取桌面图标与文件信息用于绘制，不读取文件内容，不上传。

6.2 注册表：写入 HKCU 的开机启动与屏保注册项；「系统设置」分组需 UAC 提权，主体功能以普通权限即可使用。

6.3 网络：仅用于检查更新、天气、资讯与反馈；本软件不调用摄像头、麦克风、通讯录与系统定位服务。

七、数据保留与删除

7.1 本地数据保留至你主动删除。我们不保存便签、待办与文件内容，不存在「注销账号」流程与服务器副本。

7.2 删除方式：退出程序后删除 %LOCALAPPDATA%\ZkDesk 即可清除全部本地数据；也可通过 Windows 应用列表卸载，建议先关闭开机启动与屏保注册。

7.3 第三方服务方自行保留的日志我们无权删除，如需处理请联系相应服务方。

八、未成年人保护

8.1 本软件不面向未成年人单独提供服务。未满十四周岁的用户应在监护人陪同下阅读并取得同意后使用。

8.2 如你认为我们在未获监护人同意时处理了相关信息，可通过第十条联系我们核实处理。

九、你的权利与政策更新

9.1 依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》，你有权知情、决定、查阅、复制、更正、删除个人信息并撤回同意；上述权利多可通过操作本地文件实现。

9.2 如需就我们可能持有的信息行使权利，可通过第十条提出，我们会在合理期限内答复。

9.3 本政策可能更新，文本在官网发布；重大变化会通过官网或程序提示告知，继续使用视为接受。

十、联系方式

10.1 如对本政策有疑问或投诉，可通过 GitHub Issues 联系我们：https://github.com/jojocaptain520/jojocaptain520.github.io。

10.2 未尽事宜适用相关法律法规。
